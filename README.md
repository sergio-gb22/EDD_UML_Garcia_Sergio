## *Fase 1:* Investigación Técnica
En los diagramas UML la diferencia entre un rombo (nodo de decisión) y una barra (fork) es que si el flujo se divide para elegir una sola opción (rombo) o para hacer varias tareas simultáneamente (fork)[1]
Una birfurcaión es un nodo que permite dividir el nodo de control en diferentes flujos concurrentes,permite ejecutar paralelamente las actividades, por lo que pueden estar ehecutandose silmultaneamente [2]
Un rombo define la condicion de un eventi o actividad y se utiliza para describir los cambios de estado hechos por los eventos [3]
